# Step 3 Quick Reference

## Navigation
- Open **My Notes** from the dashboard sidebar or mobile navigation.
- Select a note card to open it.
- Use **Back to library** to return.

## Shortcuts
- `Ctrl/Cmd + S` — save now
- `Ctrl/Cmd + Shift + D` — add drawing block

## In-note tools
- Rich text toolbar for headings, emphasis, lists, and alignment
- Drawing blocks with undo, redo, and clear
- Calculator button in the note header

## Persistence
- Notes autosave to `localStorage`
- Demo notes are used only as the first-load fallback
